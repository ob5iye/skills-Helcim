# Your Mac in 30 Minutes — a crash course for Windows users

Written for Helcim. Everything you already know still works; the keys and
names just moved. Read sections 1–4 on day one; the rest when you need it.

---

## 1. The one rule that fixes 80% of it

**Cmd (⌘) is your old Ctrl.** Every shortcut you know works if you press ⌘
instead of Ctrl.

| You used to press | Now press | Does |
|---|---|---|
| Ctrl + C / V / X | ⌘ C / V / X | Copy / paste / cut |
| Ctrl + Z / Y | ⌘ Z / ⌘ Shift Z | Undo / redo |
| Ctrl + S / P / F | ⌘ S / P / F | Save / print / find |
| Ctrl + A | ⌘ A | Select all |
| Ctrl + T / W | ⌘ T / W | New tab / close tab (or window) |
| Alt + Tab | ⌘ Tab | Switch apps (hold ⌘, tap Tab) |
| Alt + F4 | ⌘ Q | Quit the app completely |
| Win + L | Ctrl ⌘ Q | Lock screen |
| Win key / Start search | ⌘ Space | **Spotlight** — type any app, file, or sum |
| Ctrl + Alt + Del | ⌘ Option Esc | Force Quit |
| Print Screen | ⌘ Shift 4 | Screenshot (drag a box); ⌘ Shift 3 = full screen |
| Delete (forward) | Fn Delete | The Delete key alone works like Backspace |
| Home / End | ⌘ ← / ⌘ → | Start / end of line |
| Ctrl + ← / → (word jump) | Option ← / → | Jump by word |
| F2 (rename) | Enter | Press Enter on a selected file to rename it |
| Enter (open file) | ⌘ O or ⌘ ↓ | Enter renames; ⌘ O opens |

The **Option (⌥)** key is your old Alt. **Ctrl** on a Mac is mostly for
right-click (Ctrl + click) and a few terminal things — you will rarely use it.

## 2. Five trackpad gestures (practice these for two minutes)

1. **Click** = press anywhere, or just tap (we turned tap-to-click on).
2. **Right-click** = two-finger click/tap, or click the bottom-right corner.
3. **Scroll** = two fingers up/down. (It moves the page like your phone. If it feels backwards, System Settings → Trackpad → Scroll & Zoom → turn off "Natural scrolling".)
4. **See all open windows** = swipe up with three fingers (Mission Control). Swipe down to return.
5. **Switch between full-screen apps / desktops** = swipe left/right with three fingers.

Bonus: **pinch to zoom** works in Chrome, Preview, Maps, Photos.

## 3. Where things are

| On Windows | On Mac |
|---|---|
| Start menu | **Spotlight** (⌘ Space) or **Launchpad** (pinch 4 fingers in) |
| Taskbar | **Dock** (bottom). Dot under an icon = running. |
| System tray | **Menu bar** (top right): Wi-Fi, battery, Control Centre |
| File Explorer | **Finder** (the smiling face, far left of the Dock) |
| My Documents / Desktop | **Documents / Desktop** in Finder sidebar — and both live in Google Drive for desktop |
| Control Panel / Settings | **System Settings** (gear icon) — search box top-left |
| Task Manager | **Activity Monitor** (⌘ Space, type "activity") |
| Recycle Bin | **Trash** (right end of the Dock) |
| Notepad | **Notes** (syncs to your iPhone) or TextEdit |
| Snipping Tool | ⌘ Shift 4 (or ⌘ Shift 5 for the full toolbar + screen recording) |
| Windows Update | System Settings → General → Software Update (IT manages timing; just click Restart when asked) |
| Device Manager / Properties | Apple menu  → About This Mac |
| Minimize / Maximize / Close (top-right) | **Red / Yellow / Green** dots (top-left). Red **closes the window but not the app** (see §4). Green = full screen; **hold** green for split-screen. |

## 4. Three things that genuinely are different

**a) Closing a window does not quit the app.** Red dot closes the window; the
app stays running (dot under its Dock icon). That is normal and fine — Mac
manages memory for you. To really quit: ⌘ Q. You will almost never need to.

**b) The menu bar is always at the top of the screen**, not inside each window.
It changes depending on which app is in front. Look at the top-left to see
which app you are "in".

**c) Apps install by dragging.** If you ever download a `.dmg`, you drag the
icon into the Applications folder, then eject the disk image. But at Helcim
you should not need to: open **Self Service** (in the Dock) and click Install.
Everything there is pre-approved by IT.

## 5. Signing in at Helcim (you have the best setup in the company)

- **Unlock your Mac with Touch ID.** Your fingerprint is your password.
- **Okta is tied to Touch ID** (FastPass). When any work app asks you to sign
  in, you will see "Okta Verify" → tap the fingerprint sensor. No password, no
  code.
- You only type your Okta password if Okta explicitly asks — that happens
  after a restart or roughly every few weeks. Keep it in **1Password**.
- **1Password** fills every other password. ⌘ Shift X in Chrome opens it;
  Touch ID unlocks it.
- **Netskope** runs silently in the menu bar. If a website is blocked, that is
  the security team, not your Mac — Slack IT.

## 7. Window management (we installed helpers)

- **Rectangle**: drag a window to the left/right edge to snap it, or
  Ctrl Option ← / → for half-screen, Ctrl Option Enter for maximize.
- **AltTab**: hold **Option** and tap Tab to switch between *windows* exactly
  like Windows Alt-Tab (⌘ Tab still switches by app).
- **Maccy**: ⌘ Shift C shows your clipboard history (like Win + V).
- **Hold the green dot** on any window → choose "Tile Left/Right".

## 8. iPhone tricks (if you have one — this is where the Mac wins)

- **AirDrop**: right-click any file → Share → AirDrop → your phone. Instant.
- **Universal Clipboard**: copy on your phone, ⌘ V on the Mac. Just works.
- **Phone calls and iMessage** arrive on the Mac. Turn off in System Settings
  → Notifications if it is distracting.
- **iPhone Mirroring**: open the iPhone Mirroring app to control your phone
  from the Mac.
- **Continuity Camera**: use your iPhone as a Zoom webcam — it is dramatically
  better than the built-in one. Just hold the phone near the Mac during a call
  and select it under Video.

## 10. If something goes wrong

| Symptom | Do this |
|---|---|
| App frozen / spinning beachball | ⌘ Option Esc → select app → Force Quit |
| Mac feels slow | Apple menu  → Restart. Safe, takes ~30 s, nothing is lost (apps reopen). |
| "Okta Verify wants to..." prompts | Tap Touch ID. If it loops, Slack IT with a screenshot (⌘ Shift 4). |
| Can't find a file | ⌘ Space, type part of the name. Or Finder → Recents. |
| External monitor not detected | Unplug and replug the cable; or System Settings → Displays → Detect Displays (hold Option to reveal). |
| Screen share shows black | System Settings → Privacy & Security → Screen Recording → toggle the app on → relaunch it. |
| Scrolling feels backwards with a mouse | System Settings → Mouse → turn off Natural scrolling. |
| Anything else | Slack IT. Same-hour response for your first two weeks. |
